# Unified diff engine (SPEC-31): cost-cut ladder and backup plans

Every expensive element has a cheaper variant that keeps the invariants (derived only, no averaging, conflicts preserved, missing = unknown, ordinal display, one window). Switching is a configuration change recorded in `config_digest` (02 s5), so results produced under a backup are never confused with full results. "Trigger" = the measurable condition that makes the owner switch; decisions are recorded in `docs/qa.md` and `tasks/todo.md`.

## 2. Minimum viable unified engine (MVUE)
S0a + S0b (B-00 is complete on its own) + S1 with B-03 + S2 with B-04 + S3 with B-06 and B-21 (DATA-MAP rules a/b, EH-EQ and target consistency kept) + S4 with B-10, flag off.
- Inputs: Ghidriff run (required), stored rz-diff/BinDiff sets (optional), Ghidra configured (optional).
- Output: one row per correspondence across all sources with decision, contest strength and support components; for IR pairs: unchanged (UNCH/1) / cosmetic (COS-ADDR, COS-PSEUDO) / material / review with change classes for same-shape edits; constant-only patches surface as top-ranked `review` instead of being invisible (R03 s3: Ghidriff reported 0 of 2 constant-only edits), promoted only when S3b is added.
- Effort: about 22-31 developer-days [inf] (S0a 2-3, S0b 5-7, S1-lite 5-7, S2-min 4-6, S3-lite 4-5, S4-dock 2-3).
- Gates still required before the flag defaults on: G-U1, G-U2 (on the classes B-06 covers), G-U4, G-U8; G-U3 against Ghidriff only (B-14).

## 3. Never-cut list (removing any of these is a defect, not a backup)
Derived-only storage; per-source native values never combined; `contested` preserved; missing = unknown; ordinal display; one window; offline and no target execution; strict validation of every external file; additive persistence with backups; deterministic output; cancellation that keeps previous results; target consistency of every address operand before any `unchanged`/`cosmetic` claim; a `material` second channel that observes the same change; corroboration across two components AND two evidence classes.
