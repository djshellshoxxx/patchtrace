# BinDiff execution troubleshooting (symptom -> cause -> confirm -> fix)

Date 2026-10-14. Labels: [M] measured with the real BinDiff 8 Linux CLI; [S] primary source; [H] hypothesis, confirm first. Context: `bindiff-plan.md`, `docs/research/phase-c/bindiff-automation.md` (R), spec `docs/specs/bindiff-execution.md`.

| Symptom | Likely cause | Confirm | Fix |
|---|---|---|---|
| Probe: `probe-failed`, spawn error or no output | Wrong file (not an ELF/PE), no exec bit, missing runtime lib: Linux needs libstdc++6/libc6 only [M]; Windows needs VC++ 2015-2022 x64 runtime (`MSVCP140`, `VCRUNTIME140_1`) [X] | Linux `ldd <exe>`; Windows run `<exe> --version` in cmd, look for exit `0xC0000135` / missing-DLL dialog; check `where vcruntime140_1.dll` | Install the redist (CI step only) or choose the right file; do not point at `bindiff_ui*` |
| Probe: `--version printed no recognisable BinDiff version` | Selected path is a wrapper/script, or output buffered to the other stream | Run manually; expected `BinDiff 8 (@568181968, Sep 25 2023)` on stdout, exit 0 [M] | Select the real `bin/bindiff[.exe]`; regex scans stdout then stderr |
| Probe passes but runs launch a GUI / JVM | argv[0] basename was `bindiff_ui` (it is a **symlink to bindiff** in the deb [M]) or `--ui` slipped in | `readlink -f <path>`; argv equality test | Resolve symlinks and execute the resolved path; never pass `--ui` |
| `unsupported-version` for a good install | `--version` parsed major < 8, or a distro package of v7 or older | `<exe> --version` | Install 8 (v7 and older lack the open CLI contract the spec verified) |
| `missing-option` | Newer major renamed a flag, or `--help` text changed | `<exe> --help` (exit **1** is normal [M]); compare the flag list in R section 3 | Update required-substring list; if flags are gone, keep unsupported |
| Wrong version in results (`metadata.version` differs from probe) | Install changed between probe and run, or a different binary on a symlink | Compare `metadata.version` (`BinDiff 8 (@568181968, Sep 25 2023)`) with probe text | Warning only (spec section 2); re-probe; pin the resolved path |
| Exit 0 but **no output file** | No inputs recognised so help was printed (exit 0) [M]; or `--output_format=none`; or run in batch mode | stdout starts with `bindiff: Find similarities...`; `out/` empty | Fixed names `--primary/--secondary`; assert `output-missing`; never rely on exit 0 alone |
| Exit 1, `Invalid inputs, --primary and --secondary must point to valid files` | Input path missing/typo, or copy failed | stderr text [M]; `ls in/` | Check workdir copy step; fixed names `older.BinExport`, `newer.BinExport` |
| Exit 1, `file too small` / `parsing failed for exported file` | Zero-byte, truncated or non-BinExport2 input [M] | Run `binexport2dump <file>` (ships in the package); our C3 validator should have caught it | Re-export; fix C3 gap if validator passed it (add a regression) |
| Exit 1, `Output parameter (--output_dir) must be a writable directory` | `out/` not created, or path with non-existent parent | stderr [M] | Create `out/` before launch; short, ASCII workdir |
| Exit 1, `preparing statement 'DROP TABLE...': file is not a database` | A non-database file already at the target name [M] | `out/` not fresh | Always a fresh empty `out/` |
| Exit 1, `invalid JSON in security.bindiff.Config` | `--config` file wrong/empty (BOM, empty file) [M] | Show config bytes; must be `{}` | Write `{}` as UTF-8 without BOM; test it |
| Exit 1, `Unknown command line flag` | Typo, or a forbidden/unknown flag added [M] | argv digest | Fix argv builder; equality test covers it |
| Exit 1 with `Cannot create a valid filename, choose shorter input names/directories` | Dir + names > 250 chars [S main_portable.cc] | Length of `out` dir + `older_vs_newer.BinDiff` | Short workdir (`%TEMP%\pt-xxxx`), fixed names; on Windows MAX_PATH is 260 anyway [S] |
| Result looks wrong: similarity 0% or odd matches, same inputs as before | A user/machine config altered matching steps (`~/.bindiff/bindiff.json`) [M] | Run `--print_config` with and without the HOME; compare `config_sha256` | Keep `--config={}` and private HOME/USERPROFILE/PROGRAMDATA; never inherit env |
| Huge runtime | Very large functions/call graphs, many matching steps | `Setup:`/`Matching:` stdout lines show where time goes [M]; wall ms in `EngineRun` | Raise timeout (default 1,800 s) for that run, or diff smaller modules; baseline: 100k functions 10 s on synthetic data [M], real data slower [H] |
| Huge memory / OOM kill / non-zero exit with no message | RSS about 18x BinExport size [M]; C++ exceptions removed in v8 so allocation failure aborts [S] | Linux `dmesg`/exit 137; Windows exit `0xC0000409` or job memory limit hit | Cap inputs, lower `max_parallel`, apply `memory_limit_bytes` after S8; report `nonzero-exit` with the exit code, not a guessed cause |
| `timeout` then odd file left behind | SIGKILL during write leaves a partial `.BinDiff` (empty `function` table) and `-journal` [M] | `out/` has two files | Discard workdir unread; the importer must not run after a non-clean stop (S7 test) |
| `output-ambiguous` | `-journal` or extra file after exit 0, symlink, or non-regular file | List `out/` | Treat as failure; investigate AV (below) |
| `orientation` / `pair` error from importer | `file1` is primary = older [M]; wrong BinExport pair or swapped roles | `select hash from file order by id` vs artifact hashes | Re-run with correct `--older-binexport/--newer-binexport`; ids come from `executable_id` |
| `binexport-unbound` | Exporter left `executable_id` empty or not 64-hex (IDA may use MD5/SHA-1, U9 [H]) | `binexport2dump <file>` shows `Executable Id` | Re-export with a SHA-256 writer (Ghidra BinExport) or await the explicit-binding option (spec D11) |
| Windows: `PermissionError`/sharing violation reading or deleting `out\*.BinDiff` or the workdir | Antivirus/indexer holds the new file; process tree still alive | Process Explorer / `handle.exe`; check job closed first | Wait for process exit, retry delete with backoff (architecture scratch policy), copy then hash; never fail a valid result on cleanup |
| Windows: cannot start (`CreateProcess` access denied, 0xC0000022) | AV/SmartScreen block, exe on a noexec/locked path | Event Viewer / Defender log | Extract to a trusted dir (`%LOCALAPPDATA%\PatchTrace\runtimes`), exclude per policy; never disable AV in the app |
| Windows: containment failure (`spawn-failed`) | Assign to job fails; nested jobs need Windows 8+ and no UI limits on the new job [S] | Error code from `AssignProcessToJobObject` | Fail closed as designed; check parent job UI limits (some CI sandboxes) |
| Windows: path/Unicode issues (garbled or missing file) | MAX_PATH 260, ANSI code page, non-ASCII user name [S CreateFileW] | Reproduce with long/Unicode dir; Linux Unicode and 240-char names worked [M] | Only fixed ASCII names and a short ASCII workdir reach argv; copy inputs there |
| Hostile or corrupt `.BinDiff` (`malformed BinDiff database`, `contains a trigger/view`, LIMIT) | Tampered file, truncated by kill, or oversized | `file` shows SQLite; `sqlite3 <copy> .schema` on a **copy**; compare with R section 4 schema | Reject is correct. A genuine v8 file has 7 tables and autoindexes only [M]; add a mutation regression for any new failure shape |
| Missing JVM message from the GUI path | `--ui` or `bindiff_ui` invoked, or machine config `ui.java_binary` points nowhere | Looks for `jre/bin/java` in the install | CLI never needs Java [M]; remove the GUI launch path, do not install a JRE |
| `.deb` extraction fails or exe not runnable | `dpkg-deb` absent (non-Debian), partial download, hash not checked | `sha256sum` against pin; `dpkg-deb -I` | Use `ar x` + `tar --zstd/xz`; re-download; fail on mismatch |
| MSI admin extract yields no `bindiff.exe` | `/a` layout differs (`TARGETDIR\...`), property not honoured [H] | Recursive search for `bin\bindiff.exe`; `msiexec /a ... /L*v log` | Search the tree; else ephemeral `/i INSTALLDIR=` on a throwaway runner; offline: `msiextract` on Linux shows `ProgramFiles/BinDiff/bin/bindiff.exe` [X] |
| CI download 404/5xx or size/hash mismatch | Network, asset renamed, release re-uploaded | Status `failed(provision)` with sizes and hashes | Do not trust-on-first-use again; a human re-pins after review |
