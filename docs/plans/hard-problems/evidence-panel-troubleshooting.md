## 2. Quick diagnostics

- Count data() calls: subclass model with `calls[role] += 1`; expected first paint = 7 x visible cells [M]. Anything scaling with N is a bug.
- Time user actions: `t=perf_counter(); action(); app.processEvents(); print(ms)`; compare with plan section 3.
- Thread leak report at teardown: registry size, `isRunning()` per thread, `objectName`.
- Rich-text oracle: `Qt.mightBeRichText(s)` on every string that reaches a Qt text widget or tooltip.

## 3. Evidence note

All [M] numbers: PySide6 6.12.0, offscreen, one Linux machine, 900x500 view, 5 columns; reproduce with the S1 perf script before trusting thresholds on other platforms. Qt behaviour cited from `qt/qtbase` `dev` branch source comments; confirm any 6.13-only API against the pinned 6.12.0 before use.
