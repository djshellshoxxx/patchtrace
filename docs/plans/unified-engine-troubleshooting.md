# Unified diff engine (SPEC-31): troubleshooting (symptom -> cause -> check -> fix)

Labels: [W] Windows-specific; [inf] expected from code reading, not yet reproduced; [src] confirmed in code. Context: `../specs/unified-engine/`, `unified-engine-plan.md`, `unified-engine-backups.md` (B-xx). Never fix by relaxing a strict parser, skipping a test or hiding a contested row.

| ID | Symptom | Likely cause | Check | Fix |
|---|---|---|---|---|
| T-01 | `unified extract` -> `PT-UNIFIED-UNSUPPORTED (pyghidra-missing)` although Ghidriff runs | Setup points at another interpreter, or a user-site install is hidden by an `-I` flag | run the configured interpreter: `<python> -c "import pyghidra, sys; print(sys.version)"`; `ghidra_script.py --self-check` | use the interpreter that runs Ghidriff; the runner must not pass `-I` (03 s3) |
| T-02 | extractor exit 1, stderr shows `java.lang.OutOfMemoryError` | heap (L-03) too small for the image, or two JVMs at once | stderr tail in the `unified-run` row; was extraction parallel? | raise `max_heap_mb`; keep extraction sequential (default) |
| T-03 | Ghidra error "Path element starting with '.' is not permitted" or path too long [W] | private dir below a dot-prefixed folder or > 240 characters | `work_dir` in the request file | create private dirs with the backend validator (`_validated_ghidra_output_path` rule); move TEMP if needed |
| T-04 | `PAIR (program-hash)` in `gzf` mode | GZF of the other side, or Ghidriff skipped a duplicate file (it de-duplicates identical inputs by SHA-1) | compare GZF program SHA-256 with both artifacts | map GZFs by the in-program SHA-256 only (03 s8); identical pairs need no unified run |
| T-05 | no GZF found after a Ghidriff run | raw-cache hit (Ghidriff did not run), `retain_gzf` off, or a Ghidriff version writing elsewhere [inf] | run settings `cache_origin`, `gzf` | automatic `analyze` fallback (B-01) |
| T-06 | `analyze` mode much slower or different from Ghidriff | analyser options differ: Ghidriff applies its documented overrides (e.g. "Shared Return Calls" off above 1,000 functions) only when `--program-options` is supplied, which PatchTrace never does [src ghidriff main ~l.956] | `analysis_options_digest` of both sides | use plain Ghidra defaults (mirrors PatchTrace's Ghidriff call); both sides must share one digest (F1) |
| T-07 | `PT-UNIFIED-IR (bad-record:<field>)` on real output | script/ingest version skew (old script from another build), or a real exporter quirk | header `script_sha256` vs packaged script hash; the exact field | reinstall; if a real quirk: add a fixture and extend the validator explicitly (never loosen globally) |
| T-08 | `PermissionError [WinError 32]` on `os.replace` of an IR/result dir [W] | antivirus or indexer holds a file | Process Monitor; retry log | bounded retry (5 x 200 ms) then `STORE`; document exclusion; B-18 if persistent |
| T-09 | `sqlite3.ProgrammingError` (thread) or `database is locked` on publish | pointer row published from a worker thread, or a second PatchTrace instance | thread name in traceback; `.patchtrace.lock` | publish only in the GUI-thread slot / CLI main thread; one writer per project |
| T-10 | `PT-ENRICH-LIMIT` when publishing a pointer row | the 128 MiB enrichment total is full of other rows (unified rows are <= 64 KiB) | sizes by kind (`SELECT kind, SUM(LENGTH(body))`) | enrichment retention frees derived rows; unified retention (02 s4) frees old results; never store parts in rows |
| T-11 | frozen worker: "unknown command" or a Qt window opens | argv not starting with `unified` (dispatch in `__main__.py`), or a hand-built dev argv without C3's `worker_argv()` / `worker_env()` | `argv_digest` and provenance in the `unified-run` row | use `worker_argv()` + `['unified', '_worker', ...]` (frozen `[sys.executable]`, dev `-P -m patchtrace` with `PYTHONPATH`); B-20 |
| T-12 | `STORE (part-hash-mismatch)` | worker killed while writing, disk full | free space; worker exit reason | re-run; the previous result stays current by design |
| T-13 | results differ between runs or between Linux and Windows | unsorted set/dict iteration, `sum()` (compensated in 3.12) instead of the plain loop for MD, hashing a path or timestamp, CRLF in JSONL | diff the two `manifest.json` files; run `test_result_manifest_identical_linux_windows` | sort inputs, plain-loop MD (D-16), canonical JSON, `newline='\n'` on write |
| T-14 | MD index parity drift against `bindiff --md_index` | different block model (Ghidra BasicBlockModel vs the BinExport exporter's blocks) [inf], `bindiff_quirks` off, compensated sum, duplicate edge handling | `tools/unified/parity.py` MD histogram; one function by hand (diamond vector) | align the block model or document the delta; B-14 if unresolved after two attempts |
| T-15 | ladder far over L-35 at 60k functions | per-instruction Python objects, quadratic `next()` lookups (the C6 `assess_reports` lesson), uncapped hub neighbour sets | `cProfile`; pair-evaluation counters | columnar arrays + dict indexes + caps L-17/L-18; B-05 |
| T-16 | worker RSS explodes | all instruction blobs loaded, whole-file JSON parse, dense residual matrices | RSS per stage in provenance | stream ingest, blobs on demand, blocked buckets only; B-03 |
| T-17 | almost every row `contested` | rz-diff non-exclusive rows contest correct pairs, or a VA/RVA basis mismatch | contest strength histogram; adapter limitations (`not-comparable` sets) | weak contests sort last (never dropped); fix basis detection (06 s1) |
| T-18 | almost every row `older-only` / `newer-only` | image-base mismatch, rebased load, asymmetric IR producers, `EXTERNAL:` keys mishandled | `AddressMap` limitations; IR manifests (producer, mode, digest) | fix basis; F1 symmetry forces S0 when producers differ |
| T-19 | G-U2 finds a planted change in `cosmetic` (leakage) | unsound normaliser: an immediate masked as an address, or a target "mapped" through a wrong pair | reproduce with the mutant; inspect the proof inputs | tighten the rule (positive address evidence only; tier-A targets only), add the mutant as a fixture; never relax the gate |
| T-20 | process aborts (SIGABRT) on close or project switch during a run | a started `QThread` destroyed (Qt parent or garbage collection) | `PYTHONFAULTHANDLER=1`; thread registry | C6 pattern: no parent, module registry, `shutdown()` waits, generation counter |
| T-21 | tooltip tests fail for `unified.*` | controls created lazily, dock tab not in `roots`, duplicate WHAT text | the three tooltip tests' missing lists | construct eagerly (hidden), add roots, unique texts, no `<`/`>` |

| T-23 | `series` fails with `PT-NWAY-PAIR raw address_matches has an invalid address` | RESOLVED for `EXTERNAL:<hex>` (ce108cd); any remaining case is a genuinely malformed address | grep the raw JSON for the offending key | report it; never loosen the parser |
