## Independent review and repairs

These were fresh bounded engineering-agent reviews, not GitHub submitted human
approvals. Authors were not the sole reviewers of consequential changes. Every
reported blocker was reproduced before repair and rechecked independently.

| Finding | Repair and regression evidence |
|---|---|
| A malformed `,x64` row changed section architecture | Require a nonempty banner field. Original independent malformed-banner cases now refuse the row without poisoning following architecture. |
| Case-equivalent product/release/build labels hid duplicate/conflicting rows | Group by trimmed case-folded scope keys while retaining original text and all claims. |
| Short or ambiguous HTTP bodies received successful receipts | Require unambiguous framing and exact declared length; reject unsupported range/encoding combinations. The real HTTPResponse prefix reproducer fails before the fix. |
| Padded `chunked` header bypassed the real reader's decoder | Match the actual case-insensitive token without trimming. Two residual padded-header cases failed before `96cb0cb3`; all framing controls pass afterward. |
| Missing release hid a known Windows 10/11 generation mismatch | Compare explicit client generation independently of the derived Winbindex key. Six independently authored context/row mismatch variants now reject. |
| Conflicting advisory fixed builds collapsed into unknown | Preserve all scoped known builds and refuse their conflict; a scope assertion cannot admit an unrelated CSV build. |
| Failed inventory replay retained new manual filenames or a product change | Replay source evidence before either write; both independent corruption cases preserve decisions and current revision. |
| Keyboard deselection left a focused row selectable | Require exactly one visibly selected row. Ctrl+Space and clearSelection now disable Select, and direct dispatch after deselection does nothing. An independent real-store case previously advanced the investigation without a visible selection. |
| Replay accumulated every full source model | Group claims by import with one retained parsed source between groups. A real four-source lifetime regression fails on the original dictionary cache and passes with bounded retention. |

## Production retrieval attempt and external gate

At 2026-11-18T07:04:32Z the actual KbService production path was called with each
reviewed immutable plan's exact hosts and digest, no injected opener and no proxy
override. The support plan had only the support page above, 4 MiB maximum; its
SHA was `0bb5618148d7929744273a68d7c8e3f7179dd6a38935c09f997000231f91bdd8`.
The CSV plan had the ordered fwlink/download pair above, 16 MiB maximum; its SHA
was `f594033e24ec10cf8721ea9f3429e8e9ba6656a8c5b77f3c55165069e40eeada`.
Both specify identity encoding, 10-second connection and 60-second total budgets,
three bounded attempts and at most four exact planned redirects.

Both attempts returned **PT-KBC-ACQUIRE**, acquisition code **PT-ACQ-NETWORK**,
message `connection failed`. Direct diagnosis returned `socket.gaierror`, errno
`-3`, `Temporary failure in name resolution` for the approved support hostname;
ordinary AF_INET socket creation itself was available. No source or successful
fetch receipt was published. An inherited research proxy was not introduced into
the product transport. Production live acceptance therefore remains **blocked by
this runner's DNS/network access**, not passed by injected tests or saved files.

Shortest follow-up: run these exact preview/consent operations on an approved
runner with direct DNS and TLS access, retain resulting source/receipt digests,
and inspect any changed chain through a new plan before requesting its target.
