Python 3.13.17 and `pip install -e '.[dev,search,rules]'`. They are **not** part of the test suite: when a bug is
fixed, its reproduction becomes a regression test under `tests/`, and the script can be deleted.

Run them from the repository root, with the test helpers importable:

