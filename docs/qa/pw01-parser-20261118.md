## Implementation

`parse_inventory(raw, context, *, limits=DEFAULT_LIMITS, cancel=None)` returns
strict frozen records and raises a typed `SourceError` on fatal input,
encoding, quoting, resource, or cancellation failures. It performs no network,
filesystem, database, subprocess, or Qt operations. Its independently written
lexer enforces field and record bounds while scanning, without changing
process-global `csv.field_size_limit`.

The parser preserves original accepted fields, exact raw-source SHA-256, logical
record numbers, inclusive physical line spans, and every retained duplicate or
conflicting claim. Integer versions and sizes never pass through floating point.
Unknown section architecture resets the preceding section's interpretation.
Source columns that contradict asserted product/release/build or architecture
remain visible conflicts. Absent or unknown metadata alone does not contradict
a supplied known value. Safe non-PE names remain descriptive metadata.

PE filenames reuse the existing acquisition basename validator through one
shared inventory filename rule. Direct record validation also rejects unsafe
normalized names and inconsistent eligible metadata. An explicit validator
prevents Pydantic's `Literal[1]` behavior from coercing Boolean `true` into the
integer parser version.

Identity binds raw digest, parser version, context, and all captured budgets.
The limits use canonical JSON text in the hash payload, including the validated
floating-point timeout. Actual elapsed time, UUIDs, and filesystem paths do not
participate in identity. Final validation is followed by another cancellation
and deadline check before publication.
