## Public interfaces

`support_links.extract_links(raw, *, page_url, cancel=None, limits=LinkLimits())`
returns a frozen `LinkExtraction`. It contains the explicit validated page URL,
raw SHA-256/size, UTF-8 encoding, frozen links, scanned-link count, truncation flag
and `authenticity='unverified-local-file'`. `as_dict()` produces JSON-ready data.
`PARSER_VERSION` is 1. Each link retains a stable ID, 1-based index, parsed original
href, resolved URL or null, anchor text, nearby structural context, acceptance flag
and fixed rejection reason. No link is requested.

The parser ignores scripts, styles, templates, noscript bodies and HTML base tags.
Context includes the surrounding paragraph/list block/table row and current
section headings, including text after an anchor. SSU/servicing-stack, hash and
unrelated links remain rejected. Ambiguous attributes, unfinished anchors, unsafe
display text and truncated context cannot produce an accepted candidate. Multiple
accepted candidates remain separate. Limits bound bytes, events, depth, links,
text/context length and cooperative wall time. Byte/structure/time/URL-length
violations fail atomically; link-count truncation is explicit.

`inventory_fetch.build_plan(url, *, kind='file-inventory', redirects=())` returns a
frozen `InventoryPlan`; `parse_plan` accepts strict bounded JSON, and `render_plan`
shows the exact ordered requests, hosts, application headers, caps and digest.
The digest covers every plan field except itself using the existing domain ID
helper. JSON duplicate keys, malformed/non-finite values and altered fields fail.
Plans cannot contain repeated URLs or more than four redirects.

`fetch_source(plan, *, consent_hosts, consent_plan, offline=False, cancel=None,
opener=None, clock=..., now=..., sleep=...)` returns a frozen `FetchedSource` with
kind, original/final URLs, the actual ordered redirect chain including both
endpoints, exact raw bytes, SHA-256, UTC retrieval time and plan digest. `receipt()`
omits raw bytes and adds their size. Successful results consume the entire exact
approved chain, so receipt replay can reconstruct its plan digest.

An unexpected safe redirect returns `PT-KBC-CONSENT` with `details.proposed_plan`
and `details.preview` before the changed URL is requested. A final 200 response
earlier than the planned last URL similarly proposes a shorter chain without
reading its body. Unsafe redirects produce no consent preview. Fetching support
HTML never follows an extracted file link.

## Connection controls

The immutable plan and both exact consent inputs are checked before the opener
runs. Offline and cancellation refusals occur before DNS/socket work. The shared
acquisition `Transport._open`, `_read` and `_with_retries` supply retry, body-size,
idle-read, cancellation and total-deadline behavior. Received bytes are not
decompressed; a non-identity content encoding is rejected.

The production stdlib HTTPS opener has an empty `ProxyHandler` and disabled
automatic redirects. Its connection resolves once, validates every numeric
sockaddr in the answer, and connects to the same validated sockaddr. Any private,
non-global, loopback, link-local, multicast, reserved or site-local answer fails
before a socket is created, including mixed public/private sets. Embedded private
addresses in supported IPv6 translation forms are also refused. TLS retains
normal certificate and original-hostname verification; insecure contexts and
proxy tunnels are refused.

DNS, TCP connect and TLS share the connection budget. Response status/header reads
receive the shared sliced socket guard before parsing starts, preventing a slow
header drip from bypassing the total request deadline. Body reads use the same
guard and the existing transport limits. The DNS caller wait is cancellable and
bounded. A platform resolver already running cannot be forcibly interrupted:
at most four daemon resolver workers may remain until their native calls finish;
those workers only resolve and never open a connection. No process-global DNS,
socket or urllib behavior is replaced.
