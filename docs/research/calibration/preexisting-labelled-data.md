# Pre-existing labelled data for PatchTrace tests (research note)

Status: research, 2026-10-14. Docs only; no data, binaries or datasets are committed. Builds on `docs/specs/calibration-corpus-and-model.md` (sect. 3, 5, 17) and `docs/research/phase-c/matching-calibration-ground-truth.md` (sect. 1; corrections in sect. 4 below). Part B (known-answer open-source cases) was descoped by the coordinator on 2026-10-14: `corpus/catalog/*.json` owns it.

## 1. Answer first
- **No public dataset was found that gives human-verified older/newer Windows PE pairs with function-level patch truth.** Closest: Drift Corpus (row 18, labels made by a differ, so circular), the Assemblage-DeepHistory pin list (row 12, real MSVC/PDB truth but a recipe, not a binary release), PS3 and Lares (rows 20-21, ELF only).
- **Redistributable route = recipe.** No binary dataset below has a licence that clearly covers its binaries (they inherit per-package licences or state nothing). Publish pins + scripts + expected hashes and build in CI (rows 12, 42, 43); commit no binaries.
- **Free source-level labels (CVE -> fix commit -> changed functions) under open terms:** OSS-Fuzz vulns CC BY 4.0 (35), CVEfixes data CC BY 4.0 (25), GitHub Advisory DB CC BY 4.0 (41), CVE List V5 (40), MIT/BSD: SecBench, Big-Vul, PrimeVul, BugsC++, ARVO-Meta. They give identifiers; code text inside keeps upstream licences. Compute changed functions ourselves from the two revisions and use dataset labels only as a cross-check (ARVO admits "over 80% correctness", ReposVul untangles patches with an LLM).
- 43 entries: 38 read from primary repo files this session, 5 tagged [unv] (rows 10, 14, 23, 24, 29). Unknown licence = do-not-use.
- Best three for PatchTrace: row 12 (DeepHistory pins), rows 35/25/40 (open CVE -> commit catalogues), row 8 (DeepBinDiff ELF version pairs with symbols, local only).

## 2. Method, tags, reachability
- Unmarked facts were read in this session from the linked repo file (raw.githubusercontent.com or `git clone`) or counted from the git tree at HEAD (2026-10-14). **[unv]** = not read: host blocked, or the fact comes from a web-search summary of the primary page (paraphrase, not a quote).
- Blocked by the egress proxy (CONNECT 403, "organization policy"): arxiv.org (also export., ar5iv.labs.), huggingface.co, zenodo.org, assemblage-dataset.net, assemblagedocs.readthedocs.io, neurips.cc, nvd.nist.gov, services.nvd.nist.gov, www.cve.org, cveawg.mitre.org, api.osv.dev, api.openalex.org, api.crossref.org, zlib.net, curl.se, sqlite.org, www.openssl.org, snapshot.debian.org, tests.reproducible-builds.org, ftp.gnu.org, archive.softwareheritage.org, msdl.microsoft.com, symbols.mozilla.org. WebFetch cannot resolve arxiv.org or huggingface.co. Reachable: github.com via git, raw.githubusercontent.com, gitlab.com, pypi.org. Google Drive, Nextcloud, OneDrive and figshare links in READMEs were not tested.
- Downloaded for inspection only (scratchpad, not committed): Gemini `data.zip` (10.5 MB, listed with `unzip -l`, not extracted), two DeepBinDiff ELF files (0.57 MB, `file`/`nm` only), JSON/CSV heads. Nothing over 200 MB was fetched; large sizes come from READMEs or git-lfs pointers.
- Label codes: **ID-opt** same function across compiler options (not versions); **ID-ver** same function across versions; **FB** function start/end only; **PATCH-fn** function named as changed by a fix; **PATCH-bin** binary-level patched/unpatched; **SRC** source-level old/new files or functions (needs a rebuild); **FAM** malware family only; **WEAK** machine- or heuristic-made labels.
- Verdicts: **CI** metadata redistributable in a public repo under the quoted licence (code text inside may keep upstream licences); **RECIPE** publish pins/scripts, build in CI, commit no binaries; **LOCAL** local-only testing; **NO** not usable; **UNK** unknown (do-not-use). Engineering triage, not legal advice (SPEC-28 decision O1 stays open). For SPDX-standard licence files only the title and copyright line are quoted (" / " marks a line break in the file); the standard grant text follows in the file (heads checked). All verbatim quotes were machine-checked against the files read (87 quote pairs, 0 mismatches; case-insensitive, markdown stripped).

## 6. What this means for PatchTrace tests
1. **Tier R (redistributable CI):** rebuild from DeepHistory pins, vcpkg or Conan pins with the pinned toolchain; truth = PDB/DWARF symbol join (SPEC-28 sect. 3.1, 5.2, symbols-hidden rule). Publish pins and expected hashes, never binaries. Watch ICF, static-name collisions and incremental thunks; name joins also leave many one-sided functions (row 8, `ls` 5.93 vs 8.30: 37 old-only, 228 new-only text symbols), which map to the `no-counterpart` label.
2. **Known-answer patches:** select from rows 35, 25, 34, 30, 40 (CVE -> fix commit); derive changed functions by parsing both revisions; use dataset function labels as a cross-check only. Vul4C's SH-SL class (17 single-line patches) is the place to look for constant/bounds-only fixes (tiny true changes). No dataset labels refactor or no-op commits; those negative controls need our own commit scans.
3. **Local-only pool:** DeepBinDiff ELF pairs (symbols present), PS3 and Lares (function-level CVE patches in ELF), Drift Corpus and PatchPair to pick real Windows KB pairs; Drift labels are hypotheses, not truth.
4. **Windows system code:** truth must come from Microsoft PDBs obtained locally (Winbindex, PatchPair); redistribution stays barred until decision O1.
5. **Gap:** no public human-verified Windows PE patch-pair data with function-level truth. A small blind-labelled set (SPEC-28 sect. 5) remains necessary for shift-test and locked-test; free labels only enlarge Tier R and the adversarial N-types (N6, N12).
