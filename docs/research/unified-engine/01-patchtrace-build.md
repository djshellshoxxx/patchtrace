## 0. Shape in five bullets
- Two explicit artifacts (older/newer) -> ONE primary run (Ghidriff over external Ghidra) -> `FunctionMatch[]` in one SQLite JSON snapshot. Every other result is an additive `enrichment_entries` row or a sidecar file; the UI owns no analysis state.
- Two layers that never feed each other. L1 correspondence: Ghidriff plus optional rz-diff/BinDiff, reconciled read-only by endpoint address into a verdict. ## 3. Reconciliation and evidence: behaviour and limits
- `reconcile()` (reconcile.py:60-107) walks Ghidriff `project.matches` (changed pairings only). `_endpoints` :50 needs 1:1 and a parsable hex address, else `not-comparable`. Related secondary records = those anchored at the older OR newer address (:80). None -> `absent` (unknown); all pair exactly (older, newer) -> `agreement`; otherwise `disagreement`, kind `conflicting-endpoints` or `matches-alternative-rank-N` (:92-99; verdict unchanged). Unmatched secondary records -> `secondary_only` (:102).
- `assess_reports()` (secondary/evidence.py:41-103): any disagreement -> `contested`, tier low, index 0 (:77); else any agreement -> `corroborated`, index = min(83, 55 + 20 if bindiff + 8 if rz-diff) (:83), tier high at >=75; all not-comparable -> `insufficient`, None (:88); else `single-engine` 55 (:92). Native similarity/confidence are never read or averaged. ValueError on duplicate engines or differing row sets (:54,58).
- [run] synthetic records: Ghidriff modified(A,B) vs rz-diff one-sided A and one-sided B -> contested; removed(A) vs rz-diff A->B -> contested; removed(A) vs rz-diff one-sided A -> corroborated (63); rz-diff silent -> absent / single-engine (55); Ghidra VA `140001000` vs rizin `0x1000` -> absent / single-engine, and the rz pair lands in `secondary_only`.
- Manual corrections are reconciled like any other match (no `manual` special case in reconcile.py), so an analyst override can be marked contested by an engine [code].
- Limit 1: identity is endpoint address only and `image_base_subtracted` is always `unknown` (bindiff.py:192, secondary/contracts.py:98), so an image-base mismatch silently becomes "absent" plus one limitation line (reconcile.py:104). PE `image_base` and `raw_view.parse_entry_rva` (raw_view.py:57) exist but are unused by reconcile.
- Limit 2: Ghidriff's unchanged correspondences (raw `address_matches`) are never reconciled, so a wrong "unchanged" pair, or a function Ghidriff leaves unmatched but another engine pairs, appears only as a verdict-less `secondary_only` / engine-only row.
- Limit 3: Ghidriff-centric. There is no engine-vs-engine agreement, and engine ids are hard-coded in ~9 places (s5 row 1).
- Limit 4: index constants 55/20/8/83 are placeholders to be replaced or removed before any "confidence %" [doc multi-engine-evidence-calibration.md]; no calibration code (`patchtrace.calibration` absent; guarded import at evidence_view.py:122); no per-engine reliability; tier derives from the index.
- Limit 5: "contested wins" preserves conflicts as required but offers no triage among them; one weak engine (rz-diff raw-byte Levenshtein) can contest many correct pairs [inf].
- Limit 6: no block, edge or call-graph correspondence anywhere. Ghidriff JSON stores instructions/mnemonics/blocks as Python hash ints (docs/research.md:44; process-salted, so comparable only inside one file [inf]), hence `assembly` is usually None; BinDiff block/instruction tables are validated but not imported (bindiff.py:30-43).
- Limit 7: alternatives are modelled and displayed (evidence_view ALTERNATIVES_CAP 20) but never produced: rz-diff gives one record per function and BinDiff is forced 1:1 (bindiff.py:188).

## 4. Strengths to keep, weaknesses and noise sources already known
Keep:
- Strict frozen pydantic contracts with versioned `contract` strings, schema generation + drift CI, additive-only persistence with backup-before-DDL, fail-closed on unknown or future versions.
- Deterministic domain-separated IDs (no paths/timestamps); ownership validation of artifact/run/function/line/excerpt hash before navigation or save (`SourceLocation`, pipeline._locations_owned :89).
- Tri-state evidence (`unavailable` is not "clean"), NOT-APPLICABLE vs LIMIT reasons (signals.py:500); exact-integer ranking; one edit = one group (`edit_group_key` :435); attention separate from match certainty; AI never in scoring.
- One noise gate shared by B1 and B2: comment/whitespace/rename/reorder-only hunks seed nothing (signals.py:376-389,424); closed decompiler-temp table (:63-74).
- Raw upstream bytes preserved and hash-verified, quarantine on failure, prior results never overwritten. Engine runs: argv-only, absolute exe, private cwd, bounded streams, process-tree kill, per-engine failure isolation, per-outcome persistence on Ctrl+C, content-addressed cache keys, strict parsers, read-only SQLite import with authorizer.
- Presentation rules: per-engine native scores in separate columns, no blended number, banned-word sweep, plain-text sanitization (multi-engine-evidence-panel.md s0; evidence_view.py:98-110).
- Process: red/green regression per audit fix, fake-executable tests, live (non-mocked) workflows reported apart from pytest counts.
