## How to regenerate

```
python tools/status/build_status.py
python tools/status/build_status.py --check
```

Inputs: `docs/status/inventory/<KEY>.json`, `docs/status/meta.json` (baseline commit, baseline date, as_of, session) and `docs/status/slices.json`, a hand-maintained JSON list of objects with the keys `id`, `title`, `state`, `branch`, `pr` and `evidence` (any key may be absent and prints as "not stated"). `--check` writes nothing, prints the generated files that differ and exits 1; exit 2 means bad arguments or a malformed input.
