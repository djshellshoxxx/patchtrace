# PatchTrace GUI / CLI parity matrix (workstream F)

Baseline: `main@882d1ca0`. Produced read-only on 2026-11-11.

How it was built

- Real CLI: `python -m patchtrace <path> --help` was run for the root and every subcommand and sub-subcommand
  (106 help pages, all exit 0; raw output in `cli-help.txt` next to this file). 24 top-level verbs, 86 visible leaf
  commands in help, plus one real leaf that help does not list (`kb index sync`) and three hidden workers
  (`secondary _binexport-worker`, `unified _worker`, `rules _rules-worker`).
- GUI: `src/patchtrace/panel_manifest.py` (14 slots, 13 built, `guide` not built; confirmed by `patchtrace panels list`),
  the `QAction` set in `ui.py:1525-1569`, the Setup dialog buttons and each panel module.
- Behaviour claims in the "non-interactive?" and exit-code columns were probed against a synthetic sample project
  (`ProjectService.sample`) in a scratch directory with `stdin=/dev/null`: 109 invocations, no hang, no traceback,
  every `--json` run printed exactly one `enrichment-cli/1` document.
- Evidence class of every test named here: mocked, synthetic or fixture. Nothing in this matrix is live-native
  evidence: Ghidra, Ghidriff, BinDiff, rizin, capa, FLOSS and DiE are not installed in the sandbox and NVD, MSRC,
  Winbindex and CISA are unreachable.

Column notes

- Output formats: `text` = human text on stdout, `JSON` = one `enrichment-cli/1` envelope with `--json`. All 86
  visible leaves have `--json`. CSV exists on exactly one leaf (`strings export --format csv`).
- Non-interactive: no CLI code path reads stdin (`grep` for `input(`, `getpass`, `sys.stdin`, `isatty` in
  `src/patchtrace` finds none); consent is always a flag; child processes get `stdin=DEVNULL`.
- Exit codes documented: "SPEC-44 s4" = a per-verb row exists in `docs/specs/cli-umbrella.md` section 4 (11 built-in
  verbs only). "docstring" = only the feature module docstring states them. "help NN" = the user help page states
  them. The general 0/2/3/4/5 table is in `docs/guide/16-cli-reference.md:33-50`.
