## 5. Recommendations

**5.1 Decisions for the integration owner** (defaults; none blocks).
1. **KB-to-CVE source:** build the reverse index from CVRF monthly documents only. Discover with `Updates?$filter=CurrentReleaseDate gt <watermark>` (documented), fetch whole changed documents, key rows by `(kb, cve, product id)` with pointer; coverage on two axes (document id and watermark) because revisions land in old documents. Use SUG v2 per-CVE for context only and its `releaseNumber` as the document join key. Do not call undocumented SUG routes. CSAF becomes the CVE-first path only after probe P4 shows a KB per product.
2. **Parser rules:** Type 2 only; per-line `^(?:KB)?\d{4,10}$`, else `MENTION_ONLY`; Type 5 never an edge; keep `SubType`, `FixedBuild`, `Supercedence`, `RestartRequired`, `URL` as raw optional strings; treat hotpatch and preview rows as separate classes; Edge and other non-KB rows become unresolved. No structured filename field was found in CVRF or the SUG record, so Tier A needs CSAF (unobserved) or the KB file list (2.F).
3. **Pacing and consent:** no published limit, so default to one request at a time, >= 1 s apart, honour `Retry-After` up to 60 s, 3 attempts; show the exact URL list (SPEC-31 already requires it). Hosts to name in consent: `api.msrc.microsoft.com` (CVRF/SUG, already in `ALLOWED_HOSTS`), `msrc.microsoft.com` (CSAF, `CONSENTABLE_HOSTS`), and `www.microsoft.com` only if `security.txt` discovery were ever used (the repo default skips it). The specs disagree on the default scan window (31-B B2: 24 months, at most 60; SPEC-32A 1.4: 12 months) and the facts cannot settle it until P2 measures a monthly document (the repo's own probe says larger than 4 MiB), so start with 12.
4. **Winbindex parser fix (SPEC-08 amendment):** identity = dict key (64-hex lower-case); `fileInfo.sha256`, if present, must equal it (else skip as conflicting); md5/sha1 optional; keep one row per `(version, KB)` with `releaseDate`, `releaseVersion`, heading class, `otherWindowsVersions` expansion and BASE as a dated, non-KB baseline; carry `assemblies` component names as optional; keep `dataset` as an enum (`x64` today, `arm64` separate, Insider out of scope: it has no KB). Change the existing skip test deliberately. Pin metadata by content SHA-256. Keep `winbindex.m417z.com` as the only metadata host (SPEC-08 allowlist); the raw gh-pages bytes used here are for research only. Probe candidates with HEAD (302 present, 404 absent, other statuses retryable) and accept a candidate only when exactly one answers 302, then GET and compare SHA-256 with the key.
5. **Authenticity:** keep status `hash-matched-to-index` everywhere (the key is Microsoft's manifest digest relayed by a third party, not a signature). Windows: add the catalog path (`CryptCATAdmin*` + `WINTRUST_CATALOG_INFO`) beside the existing embedded `WinVerifyTrust`. Off Windows: `signature-unknown`. Do not add signify now (oscrypto blocker; catalog parser is reverse-engineered); if a Linux verifier is wanted later, wrap it behind a port and ship only after oscrypto is replaced or `\d+` is upstream.
6. **Catalog:** browser handoff using the first-party URL pattern plus manual import (R15); no scraping; Graph `FindByKbNumber` and WUA/`Wsusscn2.cab` only as optional, authenticated or Windows-only adapters. Investigate the KB "File information" CSV (P7) as the official KB-to-files source before building any inference tier.
7. **Packages:** header-only inventory first; checkpoint prerequisites as a DAG (never "fix introduced here"); no reconstruction before a Windows acceptance corpus; hostile-archive tests from R11.
8. **NVD:** keep pacing; the repo already retries 429 (name 429 as well as 403 in the exhausted-retries message); show the not-endorsed notice where NVD data appears; use `configurations`/`affected.lessThan` as corroboration of product and fixed build only.
9. **Symbol-server terms (owner decision):** the public symbol server page licenses its resources "to debug and test your software with Microsoft software" and forbids use "without authorization"; the linked licence page is unread (P6). Patch diffing of Microsoft binaries may fall outside that wording, so read it before binaries are fetched by default; keep per-operation consent, and never redistribute or commit fetched files.
