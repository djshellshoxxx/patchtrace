# BUNDLE licence obligations: policy gate, NOTICE.txt, LICENSES tree, THIRD-PARTY.json and the written source offer

Status: approved for build (documents only). Date: 2026-10-15. Base commit: `54fd085`. This is an engineering specification of a **policy gate**; it is not legal advice and makes no legal-compliance claim (the pin and the generated notice say the same). Game plan: `docs/plans/backend-bundle-finish-gameplan.md` step G11. Code: `tools/backend_pin.json` `license_policy`, `tools/check_backend_pin.py` (`copyleft_problems`, `unapproved_licenses`, `shipped_gpl_dir_problems`), `tools/build_backend_bundle.py` (`notice_text`, `policy_notice_lines`, `source_offer_text`, `ThirdPartyDoc`, `_third_party_components`), `tools/build_linux.py` (`license_problems`, `attach_backend`).

## 1. Purpose and non-goals

Purpose: every shipped component carries its licence texts; the GPL-3.0 Ghidriff is shipped unmodified, run only as a separate process, with its exact corresponding source inside the bundle; the GPL-2.0-with-Classpath-exception JDK has a written offer with an exact URL and digest; the machine-readable inventory and the human notice agree with the pin; a build cannot ship an unlisted GPL-family component.
Non-goals: legal interpretation of "aggregate" versus "combined work", the licence of PatchTrace itself (MIT, see repository `LICENSE`), the Qt/PySide notices of the lite app (handled by `tools/build_windows.py` `required` list), signing.

## 2. Definitions

- **GPL-family**: any SPDX expression matching `(?<![A-Za-z])(?:A|L)?GPL(?![A-Za-z])` (case-insensitive), including `GPL-2.0-only WITH Classpath-exception-2.0` (`is_copyleft`).
- **Policy entry** (`license_policy.allowed.<name>`): `spdx`, `role`, `owner_approved`, `rationale`, `shipped`, `match` (component ids), optional `approved_on`, `approved_via`. An entry covers a component only when its id is in `match` **and** the SPDX strings are identical, so a changed licence is refused again.
- **Separate process**: Ghidriff is started only as `python -I -X utf8 -m ghidriff ...` (VERIFIED `backend.py` line 587); nothing under `src/` or `tools/` imports `ghidriff` (VERIFIED by `grep -rnE "^\s*(import|from)\s+ghidriff" src tools`, no match).
- **Source offer**: `SOURCES/SOURCE-OFFER.txt` generated by `source_offer_text`.

### 3.2 Payload files

```
backend/payload/LICENSES/NOTICE.txt              required by the manifest validator (REQUIRED_FILES)
backend/payload/LICENSES/GPL-3.0.txt             copied from the Ghidriff source LICENSE; build fails if it lacks "GNU GENERAL PUBLIC LICENSE"
backend/payload/LICENSES/THIRD-PARTY.json        schema patchtrace-third-party/1
backend/payload/LICENSES/<component id>/...      licence files found in the component tree or dist-info (licenses/ subdir or top level)
backend/payload/SOURCES/ghidriff-<sha7>.tar.gz   exact unmodified source (canonical form spec)
backend/payload/SOURCES/SOURCE-OFFER.txt
backend/payload/config/runtime-policy.json
```
All are listed in `manifest.json` `files[]` with size and sha256, so a missing or altered licence file is a verification failure (`PT-BUNDLE-HASH`/`-MISSING`/`-EXTRA`).

### 3.3 `THIRD-PARTY.json` (`ThirdPartyDoc`, pydantic, `extra=forbid`, frozen)

Top: `schema` (`patchtrace-third-party/1`), `generated_by` (`build_backend_bundle/1`), `pin_sha256` (SHA-256 of the exact pin text), `built_at` (UTC, from `SOURCE_DATE_EPOCH` when set), `git_commit` (`GITHUB_SHA` or `git rev-parse HEAD`, else `unknown`), `components[]`.
Component: `id`, `name`, `version`, `spdx`, `role` (`runtime|analysis-engine|library|tool`), `upstream_url`, `artifact` {`name`, `sha256`, `size`, `url`}, `license_files` (non-empty, payload-relative, each must be in the payload), `source` {`kind` `in-bundle|offer|upstream-public`, `path`/`url`, `sha256`}, `modified: false` (literal), `process_boundary` (`separate-process|embedded-runtime`).
Validators: `ghidriff` must be `role analysis-engine`, `source.kind in-bundle`, `process_boundary separate-process`. Component ids produced: `python`, `ghidra`, `jdk`, each wheel distribution, `ghidriff`. The JDK's `source` is `offer` (URL + sha256 of `OpenJDK21U-jdk-sources_21.0.12.1_1.tar.gz`).

### 3.4 `NOTICE.txt` content (generated, `notice_text` + `policy_notice_lines`)

Header `PatchTrace analysis runtime <runtime id>`; statement that the tree is an aggregate of separate programs and nothing was modified; the Ghidriff paragraph (GPL-3.0, unmodified, separate process `python -I -m ghidriff`, no import or linking, complete corresponding source in `SOURCES/`); one line per component `name version [SPDX] artifact sha256` with up to six licence file paths; pointer to `THIRD-PARTY.json`; the licence policy block (per entry: `shipped, owner approved` / `shipped, OWNER APPROVAL PENDING` / `NOT shipped`) and, when `ghidra-GPL-dir.shipped` is false, the statement that GNU demangling of non-PE targets is unavailable.

### 3.5 `SOURCE-OFFER.txt` (`source_offer_text`)

1. Ghidriff commit `<sha>`: source included as `SOURCES/<tarball>` with sha256 `<digest of the shipped bytes>` (must equal `sha256_file`; see defect and fix in the canonical-form spec); the installed files were built from it and compared byte for byte.
2. Temurin JDK `<version>`: source not bundled; available at `<jdk_source_offer.url>` with sha256 `<jdk_source_offer.sha256>`; "valid for at least three years after the release that contains this file". Add the release tag (`v<ver>-bundle.<run>`) and the date.
Optional (owner/legal): bundle the 115,126,841-byte JDK source tarball; cost +115 MB against the size budget.

## 4. Algorithms (gates, in build order)

```
1. gate_pin:   validate_pin (every GPL-family pin SPDX listed) + release_problems
2. licences:   per component collect licence files (tree: LICENSE*/COPYING*/NOTICE*, legal/, licenses/, Lib/LICENSE.txt;
               wheels: dist-info LICENSE* at top level or under licenses/; fall back to the built source's LICENSE*;
               pyghidra borrows Ghidra's LICENSE - LICENSE_BORROW); a component with none -> PT-BUNDLE-LICENSE
3. policy:     checker.copyleft_problems(doc components, pin) + shipped_gpl_dir_problems(payload files, pin)
               -> PT-BUNDLE-LICENSE if any
4. approval:   checker.unapproved_licenses(pin); with --release -> PT-BUNDLE-LICENSE; otherwise a build warning
               "owner approval PENDING ...; this acceptance build must not be published or released"
5. files:      every license_files path must exist in the payload -> else PT-BUNDLE-LICENSE
6. app build:  tools/build_linux.attach_backend re-runs license_problems on the payload and refuses with the same code;
               provenance records license_policy_pending_owner_approval
7. publish:    the workflow runs check_backend_pin --release WITHOUT --allow-unapproved-licenses (job pin, publish=true)
```
New (G11) extracted-artifact verifier `tools/check_bundle_licences.py <extracted root>`: parse `manifest.json`, `LICENSES/THIRD-PARTY.json`; for each component assert every `license_files` path is in `files[]`; for `in-bundle` sources assert path in `files[]` and the manifest sha256 equals `source.sha256`; assert `modified is false`; assert SPDX equals the pin when the pin is available (`--pin`); assert no path starts with `ghidra/GPL/` unless the pin says shipped+approved; assert the offer text contains the manifest digest of the source tarball and the JDK offer URL and digest. Exit 0 or print `PT-BUNDLE-LICENSE: ...` and exit 1.

## 5. Error codes

`PT-BUNDLE-LICENSE` for all of the above (VERIFIED to be the most frequent code in the repository: 29 occurrences). Sample lines: `PT-BUNDLE-LICENSE: component ghidriff ships no licence file`; `PT-BUNDLE-LICENSE: owner approval pending for ghidriff, temurin-jdk; a release build is refused`; `PT-BUNDLE-LICENSE: payload ships Ghidra GPL/ files (ghidra/GPL/..., N total) but license_policy ghidra-GPL-dir is not shipped and owner-approved`; `PT-BUNDLE-LICENSE: jdk is 'GPL-2.0-only WITH Classpath-exception-2.0' and is not listed in license_policy`.

## 6. Determinism

`THIRD-PARTY.json` is `json.dumps(..., indent=2, sort_keys=True)` plus a newline; component order follows the build (python, ghidra, jdk, locked wheels in lock order, ghidriff). `built_at` and `git_commit` are the only run-dependent fields; with `SOURCE_DATE_EPOCH` set they are stable for one commit.

## 7. Security invariants

1. A GPL-family component absent from `license_policy` blocks every build, not only releases.
2. A policy entry flipped to `owner_approved: false` blocks release/publish builds (`test_flipping_an_approval_to_false_fails_the_release_gate`).
3. Ghidriff is never imported or linked by PatchTrace code; the argv uses `-I`; the environment is an allowlist.
4. Licence files are part of the hashed inventory.
5. The offer names digests, never "latest".
6. Nothing GPL is copied into the PatchTrace repository (checklist rule 7).

## 8. Budgets

Licence files under 5 MB total; NOTICE.txt under 100 KB; `THIRD-PARTY.json` under 200 KB; verifier under 5 s on 40,000 manifest entries.
