## 1. Verdict and scope
- Build a **pair-aware call-change explorer**, not a graph viewer: pure package `patchtrace.callgraph` (kernel, deltas, leads, DOT, CLI) and a "Calls" panel in the single main window: changes table, neighbours table, call tree, then a diagram.
- Core value: **rename-invariant call deltas** through raw `matches.name_matches` (all matched pairs, unchanged included; PatchTrace ignores it today) plus emitted pairs, so Ghidriff's noisy `called`/`calling` diff types become decided classes; new calls to hinted APIs and imports; groups sharing a new callee; honest blast radius and entry distance (upper bounds); N-way callee lineage; an independent `graph` lead channel; text-only DOT.
- Decisions: **no runtime NetworkX** (measured: 2.5x memory, 150 ms import, slower on 5 of 6 operations; dev-only differential oracle); small internal CSR digraph; pure-Python **ego hop-layered** layout (global layering collapses beyond about 2,000 nodes); QGraphicsView with stock items up to 2,000 nodes, **table and tree primary** (Qt exposes no QGraphicsView item accessibility); call sources pluggable (Ghidriff labels now, `program-ir/1` and BinExport2 edges later).
- Not building: whole-program extraction (unified S1, C3 worker), call counts/order/sites from Ghidriff sets, data xrefs, centrality/PageRank, Graphviz execution, a web canvas, any vulnerability or fix claim.

## 3. Standalone baseline versus PatchTrace value
- **Alone**: Ghidra's call-tree windows (one program, whole-program, interactive, no version pairing); Ghidriff (sorted name lists and `diff_type` flags, no graph, no cross-build mapping); BinDiff's call-graph view (paired, needs a BinExport, no advisory/capability/series context) [unverified: manual host blocked]; NetworkX/Graphviz (algorithms and drawing of whatever graph you hand them).
- **PatchTrace adds**: explicit older/newer orientation; analyst corrections and secondary engines as the pair map; verdicts that survive stripped builds (offline default is `--no-symbols`, so renumbering noise is the normal case); anchors in and out; provenance and staleness; series; one click to the stored code; offline.
- **Workflows**: W1 "is this `called` flag real?" (Changes tab: `renumber-only` vs `added-call`); W2 "where is the new check?" (a new function called by k changed functions is one group); W3 "does it now touch an API a patch rule or advisory names?"; W4 "how exposed is it?" (direct callers, observed path from an export or entry); W5 "what happened across builds?" (lineage matrix); W6 "send it on" (DOT/JSON); W7 triage (separate `graph` channel).
- **Charter map** (roadmap s3): 1 pair-aware = `PairMapPort`; 2 delta not inventory = classes in A3, `cannot-determine` is never removal; 3 anchors = s4; 4 triage = `GraphLead`, ordinal, origin shown, no score; 5 one click = `NavTarget` (match, line range, import row, or a stated reason); 6 provenance = `SourceInfo` and cache key 7.5; 7 offline/degrade = states E4-E6, E12, no network, nothing executed; 8 teachable = `meaning`/`next_step` per signal; 9 synergy = s5.

**7.2 Models** (pydantic `strict, frozen, extra='forbid'`, contract literal in each; sides are always `older|newer`):
- `GraphNode`: `id` (`domain_id('callgraph-node', 1, {sha, side, kind, key})`), `kind function|paired-unchanged|external|label-only|ambiguous`, `label` (sanitized, <= 512), `function_id?`, `match_id?`, `rva?`, `tier record|pairing|label`, `flags` (`import hub thunk-suspect api-hint newly-imported trace-helper`), `candidates` (ambiguous only).
- `GraphEdge`: `id`, `src` (caller), `dst` (callee), `side`, `support` subset of (`called`, `calling`; both = listed by both ends), `flags`. No version edges in call views; a paired export adds a separate `correspondence` list, never a call.
- `GraphView` (`workbench-graph/1`): `project_id`, `run_id`, `older_sha256`, `newer_sha256`, `orientation 'older->newer'`, `nodes`, `edges`, `correspondence`, `truncated`, `completeness changed-set-lists|whole-program|unknown`, `limitations`, `source: SourceInfo(source_id, version = run.backend_version, tier)`. No timestamps, so output is byte-stable.
- `Pairing`: `kind one|many|removed|added|unknown|contested`, `partners`, `via` (`manual`, `ghidriff:<first match type>`, `unified:<tier>`, `secondary:<engine>`), `engines` (every opinion kept).
- `contracts_delta.py`: `ApiHit(api, rule_id, rule_revision, family, via rule-hint|advisory-anchor|capa)`; `CalleeChange(cls same-link|added-call|removed-call|call-to-new-function|callee-deleted|cannot-determine, older_label?, newer_label?, pairing, flags, api?, reason)`; `CallDelta` (`workbench-graph-delta/1`: `match_id`, `older_function_id?`, `newer_function_id?`, `state compared|one-sided|not-comparable|unavailable`, `downgrade none|renumber-only|hub-only`, `changes` <= 500, `omitted`, `ghidriff_diff_types` (hint text only), `callers_listed_older/newer`, `limitations`); `CallGroup(callee, cls, members)`; `GraphSignal(id, rank, meaning, next_step, evidence: ClaimRef(record_id, field))`; `GraphLead` (`workbench-graph-leads/1`: `match_id`, `signals`, `origin(engine, run_id, raw_sha256, group='calls')`, `blast(direct_callers, observed_callers, unknown_frontier)`, `entry(state reached|not-reached|unknown, hops, via)`).
- `contracts_evolution.py`: `NeighbourhoodEvolution` (`workbench-graph-evolution/1`: `series_id`, `chain_id`, `builds`, `lineages[CalleeLineage(id, labels_by_ordinal, cells present|absent|unknown, events appeared|dropped|reverted)]`, `digest_by_ordinal`, `inconsistencies`, `limitations`).

**7.3 Algorithms**
- **A1 resolution ladder** (per side, first match wins, `via` recorded): (1) label equals one emitted record's `name` = `function`; several = `ambiguous` with candidates; (2) label is a key (older) or value (newer) of `name_matches` = `paired-unchanged` (no code, no lists), 1:N = `ambiguous`; (3) `FUN_<hex>` whose parsed address is in `address_matches` = `paired-unchanged` by address (addresses are never compared across builds); (4) record with `metadata.external`, `EXTERNAL:` address, or label `LIB::name` = `external` (key = lower-cased library stem + name; A/W variants per capa); (5) [default off] `thunk_X` resolves X, flagged `thunk-suspect`; (6) else `label-only`, reason `not-in-emitted-or-matched-sets` (unmatched thunks and functions under 10 bytes never reach Ghidriff's added/deleted lists).
- **A2 pair map** (callee on one side to the other): precedence manual correction (analyst control, labelled) > emitted pair (modified/added/removed) > raw `name_matches` > equality of non-default labels (flagged `inferred`, only when raw `matches` is absent). Each engine's opinion is kept; any engine disagreement = `contested`. `added`/`removed` come from Ghidriff's added/deleted lists.
- **A3 delta** for a modified pair (O older callee labels, N newer): for each o in O: partner `one` and in N = `same-link`; partner `one` not in N = `removed-call` (callee still exists, edge gone); callee deleted = `callee-deleted`; otherwise `cannot-determine`. For each n in N that is not a partner of some o: reverse partner `one` = `added-call`; callee in Ghidriff's `added` list = `call-to-new-function` when it is an internal function, but `added-call` flagged `import` + `newly-imported` when it is an added external (Ghidriff lists unmatched externals in `added`); otherwise `cannot-determine`. Flags: import, hub, api-hint, `newly-imported` (PE import-table delta from `pe_overview`), thunk-suspect. `downgrade`: `renumber-only` when Ghidriff listed a call diff but every entry is `same-link`; `hub-only` when every non-same entry is a hub. Sets only (no multiplicity). Orientation swap exchanges added and removed.
- **A4 groups**: key (callee identity, class) over `call-to-new-function`/`added-call`/`removed-call`; a group needs >= 2 changed pairs; groups are a view, member rows stay listed.
- **A5 blast and entry**: direct callers = length of the listed `calling` (complete, direct, static); closure over the CSR is observed-only; entry distance = shortest observed path from the function at `entrypoint_va`, the label `entry`, or an export name, reported only as an **upper bound** ("at most K calls") or `not-reached`; the number of callers whose own lists are unknown is shown.
- **A6 paths**: bidirectional BFS over observed forward edges, <= 5 shortest simple paths, limited to nodes that have lists (the changed set) unless a whole-program source exists; the result carries `completeness`.
- **A7 evolution**: per adjacent pair, labels of build k map to build k+1 through that pair's 1:1 `name_matches` (transitive closure = lineage); a build's callee set comes from its record in pair (k-1,k) as newer or (k,k+1) as older; no record = `unknown`, never `absent`; two records of one build are compared by digest.

**7.6 DOT export** (text only: no Graphviz dependency, no execution)
1. UTF-8 without BOM, LF, final newline, byte-identical for equal inputs; header is `//` comments built only from validated ids and hex.
2. Fixed graph id `patchtrace_calls`; node ids `n<k>` by sorted order, never user text; edges `n1 -> n2`.
3. Shapes `box` only (never `record`/`Mrecord`: their labels parse `< > { } |`); no `<...>` HTML labels; no `URL href tooltip id class image fontpath xlabel`; attribute whitelist `label shape style color fillcolor penwidth fontname rankdir constraint arrowhead`; colours from a fixed palette.
4. Label pipeline: sanitize (controls, bidi, U+2028/9 replaced), one line, truncate to 120 with `...`, then **`\` to `\\` first, then `"` to `\"`**, then join lines with the two characters `\n`. The lexer keeps `\\` as two characters and `labels.c` collapses it to one backslash, and no `\N \G \E \T \H \L` can be formed from text.
5. Paired export: `cluster_older`/`cluster_newer` labelled "Older build"/"Newer build" [unverified: cluster semantics from docs host, blocked]; inferred edges dashed, unresolved nodes dashed, correspondence dotted with `constraint=false`.
6. Write: temp file in the target directory, `os.replace` with retry on `PermissionError`, refuse overwrite without `--overwrite`, default name `callgraph-<sha12>.dot`, never derived from function names; <= GL-10.
7. Oracle test: a Python port of the four `scan.l` quoted-string rules plus the `labels.c` unescape must round-trip every sanitized label (hypothesis over all Unicode categories); goldens carry `text eol=lf`.
