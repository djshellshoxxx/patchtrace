# Outstanding specs ledger (program E)

Status: 2026-10-14. Verified against `main` 67e5a6c (includes PR #42), by reading code and tests in that tree, not by trusting spec status lines. `docs/specs/REGISTRY.md` is a snapshot at 1560531 and predates PR #42; its stale rows are listed in section 3.
Owners: A, B, C are the three instances of `multi-instance-coordination.md` (an owner here is a recommendation for the integration owner, who decides). Recommendation vocabulary: **keep** (build as specified), **keep-reduced** (build a smaller slice), **defer** (not before the stated gate), **drop** (do not build; record why).

## 1. Method

For each spec: promise (quoted in short from the file), code on main with paths, tests, what remains, owner, recommendation. "No code" means a repository-wide search of `src`, `tests`, `tools` and `.github` for the tool names found nothing (`grep -ril 'diaphora\|qbindiff\|radiff2'` returned no files).
