## Reproduced defect and behavioral uniqueness

`src/patchtrace/kbcorrelation/cli_index.py:read_input_file` was a
blocking `open(path, 'rb')`, followed by a capped read, with no regular-file
admission. It is shared by `kb index import` and the offline advisory
import in `investigation_service.py`. On POSIX, a FIFO without a writer
blocked beyond the 0.4 s bounded control (timeout exit 124). The
`O_RDONLY|O_NONBLOCK` primitive promptly opened the FIFO; `fstat`
identified it as nonregular. This is a distinct code path from PR334's
separately repaired `save_winbindex_record`. Exact source file comparisons
found the original blocking implementation on main, PR325, PR334 and
retained donor `work/winbindex-publication-20261105`; the current repair
is not justified by Git history difference alone. No full review of the
154 retained semantic heads is asserted.

SPEC-31-F was updated **before** new tests and implementation. The reader
now opens with `O_NONBLOCK` where supported, tests `fstat` on that held
descriptor for a regular file, closes on failures and reads at most
`cvrf_doc_bytes+1`. The input error remains `PT-KBC-INPUT`, oversize
remains `PT-KBC-LIMIT`, and a symlink to a regular file stays compatible.
No remote network, target file execution, parser rule changes or output
threshold changes were introduced. Concurrent regular-file mutations,
ancestor-path substitution, and host platforms lacking `O_NONBLOCK`
are **not** claimed protected.
