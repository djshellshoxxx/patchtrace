## Narrow defect and repair

`kbcorrelation.acquire._check_directory` on the retained PR #341/#g31 source checked `Path.is_symlink()` and emptiness but not `Path.is_junction()`. A Windows NTFS junction pointing to an otherwise empty directory is a distinct final-component alias and can pass a symlink-only admission predicate. This was **source-inspection evidence**. A synthetic stdlib predicate-injection control demonstrated that the old admission expression accepted a path when `Path.is_junction` was reported true, while the repaired expression refused it. No real NTFS junction was exercised in this Linux environment.

The Python `>=3.12` project already uses `Path.is_junction()` elsewhere in `kbcorrelation.wiring`. The minimal production amendment is:

```python
if root.is_symlink() or root.is_junction() or (root.exists() and (not root.is_dir() or any(root.iterdir()))):
```

Both initial pre-download and generation-31 post-stage checks call this same helper. No network-consent, stage, import, dependency, target binary, persistence, export-publication or analytical matching behavior was expanded.
