### Reuse of engineering records

Use `docs/engineering/task-ledger.json` as the task index and `docs/engineering/FEATURE_MATRIX.md` for historical scope records. Use `CONSOLIDATION_LEDGER.md`, `BRANCH_INVENTORY.md`, `INTEGRATION_QUEUE.md`, `AUDIT_FINDINGS.md` and `WORKER_HANDOFF.md` under the same directory for reconciliation, integration, defects and ownership. Update `docs/qa.md` and `tasks/todo.md` for new receipts and active work as required by the repository. Use the engineering evidence directory for commit-bound outputs. Preserve the date and provenance on older records when adding new decisions.
