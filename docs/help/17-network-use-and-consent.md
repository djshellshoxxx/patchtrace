Understand network use and consent
Network permission belongs to the operation you are reviewing. Starting a local comparison does not require configuring an AI provider.
For interpretation, Interpret selection prepares a preview. Opening that preview sends no context. Send context issues the request to the selected endpoint. Cancelling the preview sends nothing.
Check the provider kind and complete endpoint before sending. Loopback Ollama requests go to a service on the local computer. A remote OpenAI-compatible request sends the displayed context and system prompt to that service.
Ghidriff symbol retrieval has a separate setting. It is disabled by default. Enabling symbol-server lookup permits that backend feature to make network requests. It is not consent for AI interpretation or a whole-system network policy.
The reviewed acquisition tooltip describes separate confirmations for Winbindex metadata and binary retrieval. UNVERIFIED: its complete workflow and release availability require verification against the relevant acquisition sources before use.
Selecting NVD or MSRC in an analysis profile configures a provider choice. It does not itself issue or authorize every possible request.
After transmission starts, cancellation cannot recall material already sent. The interpretation transport has a documented request deadline, and cancellation can remain pending while waiting for data.
For a disconnected workflow, prepare dependencies and local inputs beforehand and enforce isolation through the operating system or disconnected machine. PatchTrace settings alone do not establish an air gap.
