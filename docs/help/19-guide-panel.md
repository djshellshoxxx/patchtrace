Use Help > Workflow and dependencies, with F1, for the existing in-application explanation. The repository guide supplies longer reading material. The synthetic Sample provides a separate authored comparison that can be explored without an external backend or AI provider.

The GDE plan proposes authored lessons, explicit step conditions, and a static hint ladder. It separates observed application state from learner progress. These plans must not be described as an AI assistant that autonomously investigates a project or completes analyst decisions.

A future lesson whose required feature is missing should say blocked and explain the prerequisite. It should not invent evidence, run a target, transmit context, or mark an unsupported task complete. Reading a lesson cannot establish that an analysis succeeded.

For now, follow the [start page](01-start-here.md), open the sample, select a changed function, read both sides, and record your own observation. Keep authored sample findings distinct from fresh analysis output.
