Guide panel
Planned. The central manifest reserves a Guide panel and Ctrl+Shift+H. Its panel module was unavailable during review. A working contextual guide in a desktop release is UNVERIFIED.
The GUI integration plan defines short teaching topics that features can supply. Each topic contains a meaning, up to four next steps, and references to relevant commands.
The intended role is to explain the state or evidence you are reviewing. A capability difference, build-environment notice, or calibration limit can require a different explanation even when the selected function stays the same.
Read the topic’s meaning before following its next steps. A teaching topic describes how to investigate; it does not add evidence to the comparison.
When a topic refers to an unavailable feature, retain its planned status. Do not assume that a documented command has been built merely because a teaching topic names it.
The established F1 action opens Workflow and dependencies help. That existing help action is separate from the planned contextual Guide dock.
UNVERIFIED: Guide search, topic history, automatic selection behavior, and spotlight navigation were not established by a reviewed implementation. They must not be presented as working controls.
Until the Guide panel is available, use the shipped workflow help and relevant Markdown topics. Check the underlying panel’s status and provenance before applying general instructions to a particular result.
