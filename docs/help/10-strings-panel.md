# Strings

**Planned:** the Strings dock is reserved at Ctrl+Shift+T and tabbed with Graph. No Strings panel implementation appears in the inspected branch. The existing static-tool adapters and the proposed pair-aware view are different delivery stages.

The WB3 plan joins older/newer strings with extraction type, function-link evidence, and advisory context. Static strings and emulation-derived strings must remain distinguishable. A string occurring in an artifact is not by itself proof that a selected function references it or that it is reachable.

The existing CLI guide describes explicitly requested static-tool runs and stored deltas. FLOSS deobfuscation is an additional emulation path with its own consent text. It does not mean PatchTrace launches the target as an operating-system process. No string extraction should start simply because a project or help page opens.

When reviewing a delta, check tool version and settings comparability before calling an item added or removed. Missing output, a failed run, or incompatible extraction settings leave the comparison unknown. Repeated strings may have distinct occurrences.

Strings can contain credentials or hostile markup. Treat them as data and inspect copied or exported text before sharing. Do not follow an embedded address as an application instruction.
