# States and remedies

Read the full state message before retrying. Its panel title, reason, and code identify what is missing. The framework distinguishes these situations:

| State | Meaning and next action |
|---|---|
| No project | Open a project before requesting project data. |
| Idle | No result exists yet; perform the named prerequisite. |
| Loading | First content is being prepared; wait or cancel. |
| Refreshing | Existing content is being updated; check its currency. |
| Ready | Content is available within its stated scope. |
| Partial | Read the missing-evidence reasons; unknown is not disagreement. |
| Stale | Use it for reference only; refresh from the current source. |
| Blocked | Resolve the named prerequisite, using Open setup when offered. |
| Error | Read the stable code; Retry starts another attempt. Copy details retains diagnostics. |
| Too large | Narrow the filter instead of assuming the visible subset is complete. |
| Unsupported | Choose supported input or obtain the required capability. |
| Cancelled | Earlier committed results remain; restart deliberately if needed. |

The plan's shared cancellation copy is “Cancelled. Earlier results are unchanged.” Its stale template ends “It is shown for reference only.” Panel-specific messages can add information. This table explains states rather than promising identical wording everywhere.

A factory failure affects the named panel. Avoid recreating the project before checking whether other panels remain usable. Review diagnostic text before sharing it.
