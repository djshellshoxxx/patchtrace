# Start here

PatchTrace compares an explicitly older and newer Windows PE binary and keeps the resulting evidence beside your review. Start with the synthetic Sample if you want to learn the workflow without configuring an analysis backend. The sample is authored demonstration data; it does not represent a fresh engine run or a model response.

For your own files, create a project, check its orientation, configure the external backend, and run a comparison or import existing raw Ghidriff JSON. Select a function relationship, read both sides, inspect disagreements, and record your conclusion. AI interpretation is optional. A changed function does not establish a vulnerability.

Use these topics in order:

1. [Create and open projects](02-projects.md).
2. [Run a comparison](03-run-comparison.md) or [import output](04-import-comparison.md).
3. [Read code and bytes](05-code-and-bytes.md).
4. [Read Engine evidence](06-evidence-panel.md) and [confidence honestly](25-reading-confidence.md).
5. Consult [states](20-states-and-remedies.md) when an operation is unavailable.

The panel topics distinguish implemented views from planned features. A reserved shortcut does not mean a panel is available. The [existing guide](../guide/00-index.md) provides longer procedures and the [QA record](../qa.md) records earlier verification.
