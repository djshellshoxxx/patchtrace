# Read confidence honestly

Keep these questions separate: do the functions correspond, what changed, does an advisory apply, and what conclusion does the evidence support? A value answering one question does not automatically answer the others.

Attention ordering prioritizes changed functions for reading. Engine values use their own native units. Unified decisions are ordinal derived labels. Model confidence text is a model assessment. None establishes that the selected function contains a vulnerability or that a patch fixes it.

Calibration requires a relevant evaluated model artifact and passing gates. The repository guide reports that no calibrated model ships. Treat any stronger current claim as **UNVERIFIED** until the release supplies its model identity, evaluation scope, and acceptance evidence. Synthetic tests alone do not establish general accuracy on vendor binaries.

Unknown is not zero or a negative vote. A missing engine run, unavailable code, incomplete catalog, or unresolved product mapping leaves a limitation to state explicitly. Keep contradictory relationships visible rather than averaging them away.

Also check shared origin. Two observations derived from one Ghidra analysis or the same bytes do not automatically provide two independent confirmations. Preserve the origin and source run in notes.

Accepting a finding records your review decision. Schema-valid citations establish traceability, not factual correctness.
