01 / HONEST STATUS

Early, vibe coded, and upfront about it.

What you are looking at, in plain terms.

VIBE CODED

Built with AI assistance

PatchTrace was vibe coded by {{cdl_name}}: AI coding agents wrote much of the code and the tests under the owner’s direction. Automated tests and CI back it, but the audits recorded in the repository were AI-assisted too, and no third-party security audit is recorded. Read before you trust.

ALPHA

Expect rough edges

Features are missing, interfaces can change and the Windows build is an unsigned, portable ZIP. Several checks are still open, listed below. It is provided as is, without warranty, under the MIT licence.

ANALYST-CONTROLLED

Offline-first, nothing silent

It analyses files statically and never runs, loads or installs the binaries you give it. Nothing is uploaded silently: downloads, CVE lookups and optional AI providers happen only after you consent and see exactly what will be sent. Credentials stay in memory for the request.

NOT CLAIMED

No calibrated confidence

Rankings are ordinal. An attention score suggests where to look first; it is not a probability, a vulnerability verdict or an exploitability estimate. Calibration tooling exists for research, but no trained model ships and scores are labelled uncalibrated.
