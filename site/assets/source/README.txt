Put the original Circuit Drift Labs logo in this folder as logo-original.png (a square PNG).

It is an input only and is never deployed. The site build (tools/site/build_site.py) turns it into
logo-512.png, logo-192.png, favicon-64.png, apple-touch-icon-180.png and og-image.png.
Without it the page shows a text wordmark. See site/README.md.
