## Implemented but not yet verified (shown on the page as such)

- Optional AI interpretation is tested with mocked transports only; live Ollama and OpenAI-compatible runs are still open.
- Fetching CVE data live from NVD and MSRC is implemented behind consent but has not been verified against the real services.
- BinDiff execution has been verified on Linux only, and BinExport2 only on synthetic files.
- A hands-on acceptance pass of the Windows ZIP on a clean machine, including screen readers and display scaling, has not been done.
